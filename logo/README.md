# Coco Brand Assets (`logo/`)

Brand imagery for Coco. The Coco brand accent is orange — **`#e85d2a`**.

| Asset | Description |
|-------|-------------|
| `ryro-logo-orange-*.png/jpg` | Logo on orange / orange-mark variants (use `ryro-logo-orange-bg-removed.png` for the main README header) |
| `ryro-logo-orange-text-white*.png` | White-text version |
| `ryro-black*.png/jpg` | Black-mark variants |
| `ryro-white*.png/jpg` | White-mark variants |

Transparent-background (`*-bg-removed.png`) variants are provided for dark and
light themes. Pick the variant with contrast against its target surface.
